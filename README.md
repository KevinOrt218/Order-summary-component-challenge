### What I learned

I practiced centering a single card both vertically and horizontally on the page, and styling the two call-to-action elements (a button and a plain link) with clear hover and focus states.

```css
.link-cancel:hover,
.link-cancel:focus {
  color: hsl(245, 75%, 52%);
  text-decoration: none;
}
```

### Continued development

I'd like to explore adding a small transition/animation when hovering the buttons, and practice building this same card with CSS Grid instead of Flexbox.

### Useful resources

- [MDN - :hover and :focus](https://developer.mozilla.org/en-US/docs/Web/CSS/:hover) - Helped me understand how to give clear feedback on interactive elements for accessibility.
